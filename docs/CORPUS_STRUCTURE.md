# Corpus Structure & Data Directory Layout (Phase 25 Reconciled)

## 1. Overview
This document specifies the physical and logical structure of the Clinical Decision Support (CDS) RAG knowledge base. The architecture enforces strict separation between the **Active Expanded Production Knowledge Base (2,204 Chunks)** and the **Frozen Golden Baseline (236 Chunks)**.

```
data/
├── sources/                         # Direct source-specific upstream files and adapters
│   ├── dailymed/                    # FDA DailyMed SPL package inserts & XML records
│   ├── icmr/                        # ICMR Guidelines for T2DM, Antimicrobial Stewardship, Pneumonia
│   ├── mohfw/                       # MoHFW Standard Treatment Guidelines (PHC/CHC Level)
│   ├── medlineplus/                 # MedlinePlus Health Topics & condition overviews
│   └── rxnorm/                      # RxNorm active ingredient maps & brand synonym dictionary
│
├── raw/                             # Raw unmodified ingested source payloads
│   ├── dailymed_raw.json            # 231 full SPL drug monographs (2,176 clinical sections)
│   ├── icmr_guidelines.json         # 8 ICMR guideline monographs
│   ├── mohfw_stgs.json              # 4 MoHFW standard treatment guideline documents
│   └── medlineplus_topics.json      # 16 MedlinePlus clinical topics
│
├── normalized/                      # Normalized canonical KnowledgeDocument & Chunk JSONs
│   ├── expanded_production_chunks.json  # 2,204 canonical chunks with full 9-field provenance
│   ├── dailymed_normalized.json     # Normalized DailyMed documents
│   ├── icmr_normalized.json         # Normalized ICMR documents
│   ├── mohfw_normalized.json        # Normalized MoHFW documents
│   └── medlineplus_normalized.json  # Normalized MedlinePlus documents
│
├── manifests/                       # Immutable cryptographic SHA-256 manifests
│   ├── model_index_lock.json        # Complete specification & lock manifest
│   ├── production_index_manifest.json # Hashes for active 2,204 production index
│   └── golden_baseline_manifest.json  # Hashes for 236-chunk golden baseline
│
├── registry/                        # Machine-readable registry of ingested sources
│   └── knowledge_base_registry.json # Registry with authority, license, and provenance metadata
│
├── indices/                         # Dense FAISS and sparse BM25 index artifacts
│   ├── production/                  # Active Production Index (2,204 vectors, 384D)
│   │   ├── index_v2.bin             # FAISS FlatIP (384D cosine similarity)
│   │   ├── meta_v2.json / .pkl      # Enriched chunk metadata
│   │   └── bm25_index.pkl           # BM25Okapi inverted index
│   └── golden_236/                  # Frozen Golden Baseline Index (236 vectors, 384D)
│       ├── index_v2.bin             # Frozen Golden Baseline Index (SHA-256 74dbf0d...)
│       ├── meta_v2.json / .pkl      # Frozen Golden Baseline Metadata
│       └── bm25_index.pkl           # Frozen Golden Baseline BM25 Index
│
├── quarantine/                      # Quarantined & unverified datasets (strictly isolated)
│   ├── medquad_legacy/              # Legacy MedQuAD NIH Q&A pairs (unverified)
│   ├── synthetic/                   # Generated/synthetic medical dialogues (isolated)
│   └── third_party_scrapes/         # Unverified web scrapes & forum discussions
│
└── evaluation/                      # Evaluation benchmarks & ground truth records
    ├── expanded_evaluation_queries.json # 50 curated clinical evaluation queries
    └── phase_25_expanded_50_eval_evidence.json # Query-level evaluation evidence
```

## 2. Document vs. Chunk vs. Vector Hierarchy

| Layer | Entity | Count in Production | Definition & Role |
|---|---|---|---|
| **Source Entity** | Upstream Reference | 231 Drug Monographs + Guidelines | Full drug labels (e.g. Metformin HCl SPL), clinical guidelines, health topic articles. |
| **Document Section** | `KnowledgeDocument` | 2,204 Sections | Discrete clinical section (e.g. Boxed Warning, Indications, Dosage, Contraindications). |
| **Retrieval Unit** | `KnowledgeChunk` | 2,204 Chunks | Segmented passage formatted with clinical context headers (`Drug: ...\nSection: ...`). |
| **Dense Vector** | FAISS Embedding | 2,204 Vectors (384D) | L2-normalized float32 vectors generated by `BAAI/bge-small-en`. |
| **Lexical Entry** | BM25 Document | 2,204 Inverted Docs | Tokenized term-frequency inverted index entries built by `BM25Okapi`. |

## 3. Architectural Invariants
1. **Count & Position Alignment**: Row $i \in [0..2203]$ corresponds to the exact same `chunk_id` in FAISS, `meta_v2.json`, `meta_v2.pkl`, and `bm25_index.pkl`.
2. **Deterministic Safety Boundary**: System is a bounded research prototype; tested emergency and injection defenses operate deterministically and fail closed when evidence is unsupported.
